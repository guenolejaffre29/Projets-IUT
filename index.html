Projets & SAE

Situations d'Apprentissage et d'Évaluation menées durant le BUT1 (Semestre 1). Le portfolio de compétences complet, avec le détail pédagogique de chaque acquis, reste consultable sur Notion.

BUT1 — Semestre 1
Réaliser

SAE 1.01 — Reversi en Java

Implémentation en binôme du jeu Reversi (Othello) en Java, jouable en terminal avec un affichage ASCII soigné : mode joueur contre joueur et joueur contre IA, grille configurable de 4×4 à 16×16.

  • Java
  • Terminal / ASCII
Optimiser

SAE 1.02 — Comparaison d'algorithmes de recherche

Implémentation et comparaison empirique de quatre algorithmes de recherche de sous-chaîne : naïf, Knuth-Morris-Pratt, Rabin-Karp et Boyer-Moore, avec protocole de mesure de performances.

  • Java
  • Analyse de performance
Administrer

SAE 1.03 — Poste de développement Linux

Mise en place d'un environnement Linux fonctionnel sur machine Windows selon trois approches comparées : WSL, machine virtuelle VirtualBox et dualboot Linux/Windows.

  • Linux
  • WSL
  • VirtualBox
  • Dualboot / UEFI
Gérer

SAE 1.04 — Base de données

À partir d'un cahier des charges, conception d'un diagramme de classe UML puis écriture des scripts SQL de création de tables et de requêtes d'insertion/suppression. Travail en binôme.

  • SQL
  • UML
  • VSCode
Conduire Collaborer

SAE 1.06 — Site de promotion d'une métropole étrangère

Contexte fictif : un développeur de retour d'expatriation crée un site pour promouvoir la métropole étrangère où il a vécu, à destination des jeunes actifs du numérique. Site WordPress multi-pages avec gestion multi-utilisateurs, boutique e-commerce de goodies, carte interactive des points d'intérêt et infographies d'indicateurs socio-économiques.

  • WordPress
  • HTML / CSS / JS
  • E-commerce
  • Cartographie
