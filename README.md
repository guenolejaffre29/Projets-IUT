# Projets-IUT

Portfolio des projets et SAE menés dans le cadre du BUT Informatique (IUT de Vannes).

🔗 **Site en ligne :** https://guenolejaffre29.github.io/Projets-IUT/
(à activer une fois dans Settings → Pages, voir plus bas)

Les projets sont organisés suivant les compétences du référentiel national du BUT Informatique. Le détail pédagogique complet (analyse réflexive, acquis par compétence) reste disponible sur le portfolio Notion :
[Portfolio de compétences](https://guenole-jaffre.notion.site/portfolio-iut-vannes?source=copy_link)

## Structure

- `index.html` — page du portfolio
- `assets/style.css`, `assets/script.js` — styles et scripts
- `assets/cv.pdf` — CV téléchargeable (à ajouter)

## Activer GitHub Pages

1. Aller dans **Settings → Pages** du dépôt
2. Source : **Deploy from a branch**
3. Branch : **main**, dossier **/ (root)**
4. Enregistrer — le site sera disponible sous peu à l'adresse ci-dessus
